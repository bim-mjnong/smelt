# Harness capability matrix — enforcement mechanisms per coding-agent CLI

Second note in the `docs/research/` convention (see
`2026-09-02-agent-enforcement.md` for the convention's start and the Claude
Code/Codex deep dive). Surveyed 2026-09-02 against primary sources only; every
claim cites the doc or repo that owns it. Feeds the multi-harness hooks preset
(Linear KOT-212).

Founder rulings this matrix produced (2026-09-02, all approved): verified tier =
Claude Code + Codex first; Gemini/Grok/Hermes/Cursor/opencode/Cline shims land as
"experimental" until smoke-tested against the real harness; KiloCode = MCP +
permissions docs; Aider = conventions-file snippet, labelled advisory. The
instruction-file snippet ships alongside every shim (belt and braces — it is also
what teaches the model to call `smelt retrieve` after a deny).

## Synthesis

1. **Full enforcement (deny + rewrite input + mutate output):** Gemini CLI and Hermes Agent — complete intercept surface via hooks. opencode close behind via plugin API (output-mutation semantics undocumented; MCP-tool bypass bug #2319).
2. **Strong-partial:** Cursor — deny + input rewrite via `preToolUse`, but output rewrite MCP-only and no static permission config (all gating is hook code).
3. **Deny-only:** Grok CLI and Cline — pre-hooks block but cannot rewrite input; neither mutates output. Grok compensates with strong declarative permission patterns; Cline only has coarse category auto-approve.
4. **MCP-only / config-only:** KiloCode — no first-class hooks (plugin `command.execute.before` is nearest); enforcement = allow/deny config + MCP substitution.
5. **Instruction-pattern-only:** Aider — no hooks, no MCP, no auto-read rules file; interception limited to interactive prompts and blunt `--yes-always`/`--no-suggest-shell-commands` flags. AGENTS.md is now near-universal elsewhere (all except Gemini-by-default and Aider).

Caveats worth carrying: opencode #2319 (MCP bypasses hooks), Gemini #20469 (policy allow ignored non-interactive), Hermes #46171 (memory tools bypass `disabled_toolsets`). Official Grok CLI = `xai-org/grok-build`; `superagent-ai/grok-cli` is third-party.
