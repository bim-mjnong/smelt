## `smelt agents` — the AGENTS.md tooling (2026-09-03) — rulings approved

Source: the guide at aihero.dev/a-complete-guide-to-agents-md. Its thesis — every
AGENTS.md token loads on every request, so keep it minimal and point elsewhere — is a
context-budget argument, which is smelt's own thesis.

| #   | Ruling                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | **Lint, never generate.** `smelt agents lint` audits; there is no `smelt agents init` — the guide itself says "never use initialization scripts to auto-generate your AGENTS.md", and smelt will not build the thing the guide warns against. The refactor (split a bloated file into root + `docs/`) needs judgment, which means a model, which Law 1 forbids: smelt does the mechanical half (split plan, link rewrite, staleness) and hands the judgment half to the user's own agent — the reranker seam again. |
| R2  | **Measure, never threshold.** The lint reports bytes and an imperative count; the budget is the user's (`agents.budgetBytes` in `smelt.config.json`), never a default. The guide's "150–200 instructions" appears only as the guide's cited figure, attributed. Same ruling as expansion rate.                                                                                                                                                                                                                      |
| R3  | **Staleness is the flagship check.** Every path-like token and every doc link in the file is resolved against the real tree; dead ones are the finding nobody else makes, and the reason to run this in CI or as a `SessionStart` hook.                                                                                                                                                                                                                                                                             |
| R4  | **Mirror drift is a finding.** `CLAUDE.md`/`GEMINI.md` copies that have diverged from `AGENTS.md` are detected; making them symlinks is offered, never done silently — the install discipline of `smelt hooks`.                                                                                                                                                                                                                                                                                                     |
| R5  | **Dogfood first.** Run the lint on this repo before shipping it; if it finds nothing, the mutation runner says whether the repo is clean or the linter is vacuous.                                                                                                                                                                                                                                                                                                                                                  |
| R6  | **Imperatives are a labelled heuristic.** Count lines opening with a verb or "always/never/do not/must/should" (rule `imperative-line`, the matched verb in the explanation). Report it as "imperatives (heuristic)" beside bytes — never as a precise figure.                                                                                                                                                                                                                                                      |
| R7  | **Seven advisory rules, one strict switch.** `dead-path`, `dead-link`, `forcing-language`, `structure-dump`, `generated-boilerplate` (softest; its explanation says so), `language-rule`, `mirror-drift`. Findings exit 0; `--strict` makes any finding exit 1 for CI. Every explanation cites the guide's own phrasing.                                                                                                                                                                                            |
| R8  | **Lint the merged set.** Every `AGENTS.md`/`CLAUDE.md`/`GEMINI.md` in the tree, because the guide says nested files merge with the root — so the _sum_ is what an agent loads and the honest number to report. Content repeated at two levels is rule `restated-at-level`. Built on `RepoReader`.                                                                                                                                                                                                                   |
| R9  | **smelt gets its own `AGENTS.md`**, written by hand to the guide's minimum checklist (one sentence, `pnpm`, the `pnpm verify` gate, pointers to CONTEXT.md and ARCHITECTURE.md), with `CLAUDE.md` as the symlink the guide recommends. Then linted by the tool it tests: a rule tripped by a minimal file means the rule or the guide is wrong, and either answer improves the tool.                                                                                                                                |
| R10 | **Architecture wave first.** A1–A3 move the registries and the site generator `smelt agents` plugs into; building on the moved ground avoids another round of reconcile commits.                                                                                                                                                                                                                                                                                                                                    |
